# 家族共有アプリ

家族みんなが別々のスマホから**同じデータ**を見て・編集できる、家庭用の共有アプリです。
データは Supabase（PICKLE HUB と同じプロジェクト）に保存され、テーブルはすべて `fam_` 接頭辞です。

## 入っている機能（6つ + 今日のボード）

| 機能 | 内容 |
|---|---|
| 📋 今日のボード | 期限が近い食材・今日の気分・歯磨き状況・偏頭痛リスクを1画面に集約 |
| 🔍 どこだっけメモ | 物の名前・置き場所・一言メモ・分類を記録。大きな検索バーと分類チップで検索、編集・削除 |
| 🧊 冷蔵庫つかいきりタイマー | 食材を購入日・賞味期限で登録。期限2日以内は「今日これ使って！」に表示、カテゴリ別の使い切りアイデア付き。使い切った／捨てたの記録も残ります |
| 🌤️ 家族の気分天気 | 家族それぞれが今日の気分を天気（🌞快晴〜⛈️雷雨）＋ひとことで共有。7日分の一覧つき |
| 🪥 歯磨き記録 | フロントカメラを鏡にしたガイド付きセッション（10か所×15秒＝2分30秒）。朝・夜の完了、スター、連続日数を家族で共有 |
| 🌦️ 偏頭痛チェック | 東海市周辺の気圧（Open-Meteo、キー不要）と体調チェック（睡眠・ストレス・肩こり）でリスクを推定し、頭痛が起きたかと一緒に記録・履歴表示 |
| 🔤 英語学習 | ABC・英検5級レベルの単語60語＋フレーズ6つ。音声は端末の読み上げ機能（speechSynthesis）を使用。聞いて選ぶクイズ、おぼえた単語・スター・バッジ・スタンプを子どもごとに保存し、家族が進み具合を見られます |

## セットアップ手順

### 1. データベースを用意する（1回だけ）

1. [Supabase](https://supabase.com) で PICKLE HUB と同じプロジェクトを開く
2. 左メニューの **SQL Editor** を開く
3. `setup.sql` の中身を全部貼り付けて **Run** を押す（何度実行しても安全です）

### 2. アプリを公開する

1. GitHub で新しいリポジトリを作る（例: `family-share-app`）
2. `index.html` をアップロードする
3. リポジトリの **Settings → Pages** で GitHub Pages を有効化する
4. 発行された URL がアプリのアドレスになります（スマホのホーム画面に追加すると便利です）

### 3. 家族で使い始める

1. 最初の一人が URL を開き、「新しく家族を作る」から家族名・自分の名前・4桁PINを登録 → **招待コード**が発行されます
2. 家族にはその URL と招待コードを伝えます
3. 家族は URL を開き、「メンバー登録」で招待コード・自分の名前・自分のPIN（4桁）を登録
4. 次回からは「ログイン」（招待コード＋名前＋PIN）で入れます

## 注意事項

- **セキュリティについて**: このアプリは招待コード＋名前＋PINをアプリ側で照合する簡易方式で、データベース側は anon キーからの読み書きを許可しています（`setup.sql` の RLS ポリシー）。家庭内のメモ用途に限った割り切りです。お金・医療・住所などの重要な情報は入れないでください。PINも他で使い回している番号は避けてください。
- **歯磨きのカメラ**は鏡として端末の中だけで使います。映像が保存・送信されることはなく、共有されるのは「できた」記録だけです。カメラが使えない環境ではタイマーだけで進められます。
- **偏頭痛チェック**は気圧と体調からの目安で、医療診断ではありません。
- **英語の音声**は端末の読み上げ機能を使うため、端末やブラウザによって声が異なります。
- データは世帯（household）単位で分かれているので、別の家族が同じ仕組みで使っても互いのデータは見えません（招待コードが鍵になります）。
